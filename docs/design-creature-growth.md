# 设计：健康小管家的异变类型与品质体系 v2

状态：设计稿（2026-09-16）。当前线上跑的是 v1（5 个异变位、11 件部件、只进不退、N/R/L 三档）。本文在 Codex 制作体型与眼型批次期间成稿，结论要么落到 `src/core/pixelcat.ts`，要么变成给 Codex 的美术请求。参考对象是 CryptoKitties（以太猫），但只借机制不借经济。

## 1. 要解决的问题

v1 的实测曲线：一只猫中位 **28 笔记录**就把 5 个槽位全部升到顶，之后只剩表情在换。按一天记 5 笔算，不到一周就"养满了"。这让「每记一笔都有看得见的变化」退化成「每记一笔都换个表情」，长期驱动力消失。

同时 v1 的升级规则是「同级或更高的任意部件」，所以猫的变化读起来是**随机替换**而不是**成长**：小翅膀可能直接变成龙翼，也可能变成毫无关系的羽翼，没有叙事连续性。

## 2. 从以太猫借什么

| 借 | 以太猫的做法 | 本项目的译法 |
|---|---|---|
| 突变阶梯（mewtation） | 同族低阶基因组合可升阶，共 4 层 | **进化链**：槽位内的有序序列，异变沿链升一阶，而不是随机换 |
| Purrstige 特性 | 部分性状只能突变得到，初始猫不可能有 | **顶阶只能升不能生**：L 级部件孵化与空槽直接掷都不会给 |
| 颜色作为独立性状 | base / highlight / accent color 各自是一条性状 | **调色板作为第二品质轴**，像素画里换色几乎零美术成本 |
| Fancy Cat 配方 | 特定 cattributes 组合解锁具名限定猫 | **称号配方**：特定组合解锁名字与徽章，纯文本零美术 |
| 稀有度由分布体现 | 稀有度是人群占比，不是标签 | 图鉴显示「你养过的 N 只里出现过 M 次」，标签与实际分布并列 |

**不借**：繁育与交易（这是单机日记，没有经济）；256 位基因组与隐性基因（没有配偶就没有隐性基因的意义）；世代稀缺（gen0 值钱会鼓励频繁回炉，与"陪伴一只久一点"冲突）。

## 3. 设计边界：美术成本是不对称的

这条决定了体系的形状，比任何美学偏好都硬：

- **绑毛色的槽位**（耳、颈、尾）：部件要和周围毛发衔接，每件要出 `6 毛色 × N 体型` 张。
- **不绑毛色的槽位**（额顶、背、以及新增的氛围）：完全覆盖或悬浮，每件 **1 张**。

所以：**成长深度要放在不绑毛色的槽位上**；绑毛色的槽位保持浅。新部件在设计时应优先做成"完全覆盖式"，以便脱离毛色。

## 4. 性状分三类

| 类 | 何时定 | 是否有品质 | 包含 |
|---|---|---|---|
| 身份性状 | 孵化时定型，终生不变 | 无 | 体型 body、毛色 coat、瞳色 eyeColor |
| 成长性状 | 每次记录推进，只进不退 | 有（N/R/L） | 额顶 crown、耳 ears、颈 neck、背 back、尾 tailTip、**氛围 aura（新增）** |
| 横向性状 | 随时可换，无优劣 | 无 | 表情 expression、眼型 eyeShape |

横向性状是关键配套：它让「满级之后每笔仍有可见变化」成立，也让成长期里没升阶的那些笔不空手。Codex 正在做的眼型批次直接落在这一类。

## 5. 进化链

一个槽位下有若干条**链**，链内自低到高排列。异变的主路是「沿当前所在链升一阶」。

当前 11 件部件的归位（括号是缺口）：

| 槽位 | 链 | N | R | L | 绑毛色 |
|---|---|---|---|---|---|
| 背 | 翼链 | 小翅膀 | 羽翼 | 龙翼 | 否 ✅ 唯一完整 |
| 额顶 | 角链 | 小龙角 | （缺） | （缺） | 否 |
| 额顶 | 鹿角链 | 鹿角 | （缺） | （缺） | 否 |
| 额顶 | 光链 | （缺） | （缺） | 光环 | 否 |
| 颈 | 鬃链 | 小狮鬃 | 颈膜 | （缺） | 鬃绑、膜不绑 |
| 尾 | 焰链 | 分叉尾 | 焰尾 | （缺） | 叉绑、焰不绑 |
| 耳 | 鳍链 | 鳍耳 | （缺） | （缺） | 是（最贵） |
| 氛围 | 待定 | （缺） | （缺） | （缺） | 否 |

**缺阶自动跳过**：升级时取「当前阶之上、本槽位内存在的最低阶部件」，同阶多个按权重挑。这保证美术没补齐时体系照常运转，也保证现在的光环仍然可达（额顶只有 N 和 L 时，N 直接升 L）。

**转链**：到达链顶后，小概率允许转到同槽位另一条链的同阶（例如角链顶转鹿角链顶）。这给满级的猫留一点后续变化，但不降级。

## 6. 顶阶只能升不能生

L 级部件不出现在孵化与空槽首次生长的候选里，只能从 R 升上去。这样传说部件天然带一段"养出来的"历史，而不是开局运气。

## 7. 颜色作为第二品质轴

像素画用索引调色板，换色不需要新图。给每件部件声明可替换的色槽与若干具名变体：

- 焰尾：橙焰（N）／青焰（R）／紫焰（L）
- 光环：金（N）／银（R）／虹（L）
- 翼：乳白（N）／墨（R）／曜金（L）

部件的最终品质 = `max(部件阶, 颜色阶)`。颜色在异变时可以单独升，算作一次可见变化。

**这是整个设计里性价比最高的一条**：变化空间乘以 3，新增美术 0 张。代价是需要 Codex 在像素目录里为资源声明可替换色槽（见第 12 节的请求 5）。

## 8. 称号配方（Fancy Cat 等价物）

特定组合解锁具名称号，显示在气泡和图鉴，纯文本零美术：

| 称号 | 条件 |
|---|---|
| 炎龙 | 角链顶 + 焰尾 + 翼链顶 |
| 天使 | 光环 + 羽翼 |
| 深渊 | 鳍耳 + 颈膜 + 分叉尾 |
| 林神 | 鹿角链顶 + 苔色调色板 |
| 六合 | 六个成长槽全部到 L |
| 素猫 | 满 60 笔仍保持六槽全空（反向成就） |

配方是长尾目标：满级之后仍有「凑出某个组合」可做。

## 9. 数值与成长曲线

规则：**每笔记录必有一次可见变化**；其中「升级」的概率随已升阶数递减，其余为横向变化（换表情／换眼型／同阶换色）。

- 升级概率 `p = 1 / (1 + 已升阶数 / 1.5)`，首笔必升级，之后逐步变慢。
- 挑槽位时**空槽权重 ×3**（广度优先）：先让猫长齐，再让它长强。
- 空槽首掷给 N；已有部件按链升一阶；顶阶按小概率转链或升色。

4000 次模拟（6 槽 × 3 阶 = 18 次升级）：

| 里程碑 | 中位笔数 | 折合（按 5 笔／天） |
|---|---|---|
| 首件稀有 | 10 | 2 天 |
| 六槽全部长出东西 | 27 | 5~6 天 |
| 首件传说 | 31 | 6 天 |
| 全部满级 | 116（10~90%：83~158） | 3~4 周 |

对照 v1：全满中位 28 笔。新方案把成长期拉长约 4 倍，且前期观感更快（27 笔就长齐，v1 要等随机填满）。

## 10. 图鉴与代数

- 图鉴按 `槽位 × 链 × 阶` 排格子，显示已收集／未收集，以及每件在你养过的猫里出现过几次。
- 回炉重造让代数 +1，只作记录展示，**不给任何数值优势**——避免鼓励刷回炉。
- 称号进图鉴，未解锁的显示条件。

## 11. 与像素包的关系

本体系是 nutri 侧的玩法规则，产出的是**表现型**（体型／毛色／瞳色／眼型／表情／五个成长槽）。像素包只负责「这个表现型长什么样」。两件事的边界与 QMonster 契约一致：

- 新增槽位（氛围）需要进表现型，是对契约的扩展，要和 Codex 对齐字段名。
- 颜色轴需要目录支持可替换色槽，属于美术侧能力。
- 体系可以先于美术落地：缺阶跳过规则保证美术没到位时不崩。

## 12. 给 Codex 的美术请求（按性价比排序）

| # | 内容 | 张数 | 解锁 |
|---|---|---|---|
| 1 | 氛围槽 3 件（如 尘光 / 落瓣 / 星轨），不绑毛色，画面四周的稀疏粒子 | 3 | 一整个新成长槽 |
| 2 | 额顶补链：角链 R+L、鹿角链 R+L、光链 N+R | 6 | 额顶从 1 阶变 3 链 × 3 阶 |
| 3 | 尾 L、颈 L，做成不绑毛色的覆盖式 | 2 | 两条链补全 |
| 4 | 部件的调色板变体声明（不是新图，是目录里声明可替换色槽 + 具名变体） | 0 | 变化空间 ×3 |
| 5 | 耳链 R+L（绑毛色，最贵，放最后；或设计成完全覆盖以脱离毛色） | 6×体型×2 | 最后一条链 |

前三项共 **11 张不绑毛色的图**，就能把体系从「5 槽、11 件、一周满级」推到「6 槽 × 3 链 × 3 阶、三四周满级」。

## 13. 待定

- 氛围槽是否要做（它是最便宜的深度来源，但会让 64px 画面更满）。
- 颜色轴走不走（需要 Codex 在目录侧支持）。
- 成长期目标 116 笔（3~4 周）是否合适，还是应该更长。
- 称号只做文本，还是配一个小徽章图。

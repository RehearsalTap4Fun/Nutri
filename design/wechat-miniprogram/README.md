# 饮食日记 · 微信小程序应用图标

## 交付物

| 文件 | 用途 |
|---|---|
| `logo-144.png` | **上传用**。144×144，微信小程序头像的建议尺寸 |
| `logo-512.png` | 母版。商店截图、宣传物料、以后重新导出用 |
| `logo.svg` | 源文件。改动从这里改，再跑 `export.mjs` 重新导出 |
| `export.mjs` | 导出脚本，`node export.mjs` |
| `preview-wechat-surfaces.png` | 在微信三个真实场景里的效果（列表 56、下拉任务栏 48、启动页 144），与现版 PWA 图标并排 |
| `preview-circle-safety.png` | 圆形裁切安全区核对图 |

上传位置：小程序管理后台 →「设置」→「基本设置」→「小程序头像」。两张 PNG 都不含透明通道（3 通道），微信对头像不接受透明背景。文件 3.6 KB / 12 KB，远低于任何体积限制。

## 为什么不能直接用 PWA 的那张

`public/icons/icon-512.png` 是按桌面与手机主屏设计的，那里图标最小也有 60~80px。微信把头像用在更小的地方，两个问题会暴露出来：

1. **细节在 40~56px 下消失。** 碗底那两条小脚（12px 线宽）在 56px 下只剩 1.3px，糊成两个灰点；蒸汽的 S 形曲线也化开了。
2. **主体偏小。** 微信在下拉任务栏和启动页把头像裁成圆形，PWA 那张的最远像素只到半径 227（裁切半径 256），圆内还剩一圈空地，在列表里跟旁边的小程序比会显得小半号。

## 微信版本改了什么

| | PWA 版 | 微信版 |
|---|---|---|
| 主体最远半径（画布 512） | 227 | **236** |
| 色块墨线 | 10 | **16** |
| 碗的墨线 | 12 | **18** |
| 蒸汽墨线 | 12 | **20** |
| 碗底小脚 | 有 | **去掉** |

- **主体放大并对圆形归心。** 先求内容的最小外接圆，把圆心移到画布中心，再缩到半径 236，给圆形裁切留 20px（约 4%）余量。安全区核对见 `preview-circle-safety.png`：红线是裁切边界，蓝虚线是本图最远像素，中间那圈米色是余量。
- **墨线整体加粗。** 岸线是这套视觉语言的识别点，加粗后在 48px 下仍是实线而不是灰边。
- **去掉碗底小脚。** 它在 56px 以下一定看不见，留着只会在缩图时糊成噪点。这是与 PWA 版唯一的造型差异，图标整体仍是同一个形象。
- 配色、不规则色块、白碗、右上角黄点全部保持不变。

## 改动方式

改 `logo.svg`，然后在本目录跑：

```bash
node export.mjs
```

它会重新导出两张 PNG 并打印尺寸与透明通道状态（有透明通道就是出问题了，微信不接受）。nutri 本身不依赖 sharp，脚本借用同机 `~/Demo/RandomPet-master` 里的那份；换机器时改脚本顶部那一行路径。

SVG 里主体包在一个 `transform` 里，那组数字就是上面说的归心与缩放，改造型时不要动它；如果造型的外接范围变了，重新求一次最小外接圆再调。

## 不在本次范围

小程序的 **tabBar 图标**是另一套资源（建议 81×81，每个标签要 normal 与 selected 两张，且通常是单色线性图标，与应用图标不是一种东西）。需要的话另说。
